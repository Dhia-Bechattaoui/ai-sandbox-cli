# Agent Workflows: Project Setup

1. **Initialization:** When starting a new feature, always verify the current state of the workspace using `list_dir` or `view_file`.
2. **Context Gathering:** Check `plan.md` to ensure alignment with the user's chosen direction before writing code.
3. **Execution Steps:**
   - Define interfaces/types first.
   - Implement core logic.
   - Attach UI/CLI binding.
4. **Verification:** Always run a quick compile check or test before presenting to the user.
